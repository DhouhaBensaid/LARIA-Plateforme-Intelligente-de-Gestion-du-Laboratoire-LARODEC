# LARIA-Plateforme-Intelligente-de-Gestion-du-Laboratoire-LARODEC
Le projet LARIA vise à mettre en place une plateforme web centralisée, intelligente et déployable, capable  d'assurer la gestion intégrée des activités du laboratoire, la production de rapports conformes aux exigences du  ministère et l'alimentation d'un site web institutionnel de LARODEC à partir d'une base de données unique.
